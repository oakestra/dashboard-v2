# __LABEL__ addon

Addon UI for the Oakestra dashboard, generated by `pnpm create:addon`.

`@oakestra/dashboard-sdk` and `@oakestra/ui` come from npm once they are published; until then
install them from packed tarballs of the dashboard repository (`pnpm pack:check` shows how).

```sh
pnpm install
pnpm dev        # http://localhost:__PORT__/mf-manifest.json
pnpm test
pnpm build
docker build -t addon-__NAME__-ui .
```

Open a development shell with
`?addon-override=__NAME__=http://localhost:__PORT__/mf-manifest.json`. `marketplace-definition.json`
is the definition to register in the marketplace once the image is pushed. Name (`__NAME__`), class
prefix (`__PREFIX__`) and port (`__PORT__`) are set in `vite.config.ts` and `src/addon.css`; see the
addon developer guide of the dashboard repository for what must match.
